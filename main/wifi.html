Configurar Wi-Fi

Consultando modo de red...

Conecta el ESP32 a una red de 2,4 GHz o crea una red propia para acceder al panel sin router.

Déjala vacía solo si la red es abierta. Vacía conserva la contraseña actual. Usuario del panel: admin. Crear una red requiere una clave de 8 a 63 caracteres.

Abrir panel energético y OTA

Restablecer configuración

Olvida la red, su contraseña, el modo de conexión y la contraseña web. Tras reiniciar, configura de nuevo desde la pantalla táctil. No cambia ajustes del Axpert.

En modo de red propia abre http://192.168.4.1/. Es normal que el teléfono indique «sin Internet». No se abre un portal automáticamente. HTTP no cifra el tráfico: usa solo redes de confianza.
